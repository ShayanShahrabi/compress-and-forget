# Data and artifacts

This directory contains released experimental artifacts generated by the project.

- `combined_raw.csv.gz`: trial-level main results used for the paper's primary analyses.
- `reconstructed_trials.csv`: deterministic reconstruction of trial subject/value sequences used for same-key intrusion classification.
- `numeric_token_lengths.csv`: numeric token-length stratification used as a robustness check.
- `vocab_manifest_*.json`: tokenizer-specific word-vocabulary filtering manifests.
- `ablation/`: results from the forced language-model-head quantization ablation.

## Included follow-up artifacts

- `followup/sampling/<model>/`: nine released completion CSVs in total, plus trial/vocabulary manifests. Each prompt has five completions per precision (temperature 0.7, top-p 0.9). Qwen: 300 mood prompts at k=64; Mistral: 100 prompts at k=16; Phi: 500 prompts at k=8. These are not three equally sized or identically composed samples. Only Mistral has an archived environment report.
- `followup/representation/<model>/`: trial/vocabulary manifests only. Raw geometry CSVs (about 543 MB total, with two Qwen files over 200 MB each) are omitted from normal Git history. Cleaned layerwise summaries are in `../analysis/verified/followup_layerwise_verified.json`; no public download location for the omitted raw files is established by this update.

The available trial manifests can describe more candidate trials than the corresponding released CSVs; use observed CSV keys for actual coverage. Compact geometry summaries regenerate the manuscript curve but not raw states. Raw centered-probe NPZ arrays and the exact modified execution-script hash are unavailable here.

See `../docs/REPRODUCIBILITY.md` for replay/version caveats, preserved versus recomputed outputs, and data/summary provenance. Existing follow-up runners are described in `../src/FOLLOWUP_EXPERIMENTS.md`; they are not a guarantee of identical historical results.

The model weights themselves are not included. They should be downloaded from their official Hugging Face repositories and used according to their licenses.
